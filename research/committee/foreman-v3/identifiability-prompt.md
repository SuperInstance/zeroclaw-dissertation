## SETUP

A "room" is observed through consecutive windows. Each window yields a unit vector
z_i ∈ S^{d-1} ⊂ R^d with d = 7 (seven "dials": mood, volume, earnestness, cynicism,
joke_landing, panic, presence; each window's dial vector is z-standardized to [-1,1]^7 and
then unit-normalized, so each z_i lies on the sphere S^6). The room STATE at a snapshot is
the unordered multiset s = {z_1, ..., z_N} — an empirical measure on S^6, i.e. a point of
(S^6)^N / S_N (quotient by index permutation), N ≥ 10.

Dial semantics fix a DISTINGUISHED ambient frame: there is a fixed unit vector ŵ ∈ R^7
("warmth direction", e.g. positive on mood/joke_landing, negative on panic/cynicism).
Rotations of ambient R^7 are NOT symmetries of the problem: only the component of rotation
that fixes ŵ-and-its-orthogonal-complement structure... more precisely, no non-identity
ambient rotation is guaranteed to preserve room semantics. Keep this in mind for Q2.

Physical constraint on rooms (dynamics): rooms are generated by bounded dynamics —
(a) agent acclimation: each agent embedding a(t) relaxes exponentially toward the current
    room mean direction: a(t) = r + (a(0) − r)·e^{−βt}, β = per-agent skill rate;
(b) charisma pull: the room mean is pulled toward a strong agent:
    r' = r + (a − r)·(1 − e^{−γn}), with blend factor (1 − e^{−γn}) ≤ 0.15 per event;
(c) switch events: at discrete times the room re-anchors: the generating distribution's
    mean direction rotates by a finite amount instantaneously.

## CANDIDATE OBSERVABLES ("room hashes")

- H1(s) = (μ̂, ρ), r̄ = (1/N)Σz_i, μ̂ = r̄/‖r̄‖, ρ = ‖r̄‖. (First moment only — what the
  dead reader effectively used; warmth = ŵ·μ̂ is a scalar functional of it.)
- H2spec(s) = (μ̂, ρ, λ_1..λ_6): eigenvalues of the tangent covariance
  C = (1/N)Σ(z_i − μ̂)(z_i − μ̂)^T restricted to the tangent space T_{μ̂}S^6.
- H2full(s) = (μ̂, ρ, C): the full 6×6 tangent covariance, expressed in a fixed
  dial-derived tangent frame (so C carries eigenvector alignment, not just spectrum).
- H3(s) = the empirical measure itself (sorted point multiset) — the trivial hash.
- H4(s) = (H2full(s), A_1), A_1 = (1/(N−1))Σ(z_i − μ̂)(z_{i+1} − μ̂)^T (tangent-restricted
  lag-1 autocovariance of the ORDERED window sequence; all hashes above ignore order).

## QUESTIONS (prove or refute each, with explicit counterexamples where applicable)

Q1 (Inherited blindness). Prove or refute: H1 is invariant under every perturbation of the
point cloud that preserves r̄. Exhibit the fooling class explicitly. Is Fact 1's failure

Q2 (Second-order spectrum counterexample). Prove or refute: H2spec has a nontrivial fiber.

s ≠ s' on S^6 with identical (μ̂, ρ, spectrum of C) but genuinely different configuration
(e.g. related by a tangent-space rotation mixing two dial axes — remember dial semantics
make such rotations physically distinct rooms). Give the 6-decimal float64 verification.

Q3 (Full second-order completeness fails). Prove or refute: H2full also has a nontrivial
fiber — construct two clouds with identical μ̂, ρ, AND identical full tangent covariance C,
but different third-moment structure. Numeric instance to 6 decimals.

Q4 (Dimension/moment lower bound). For N points on S^6 with N large: no bounded-order list
of moments is injective on empirical measures. State and prove the cleanest true form you
can (moment problem / dimension count). What is the minimal provably-injective observable,
and what does it cost (dimension, continuity, collision behavior under float64)?

Q5 (Temporal blindness). Prove or refute: every order-free observable (any function of the
unordered multiset, including H3) is invariant under window-sequence permutations — blind to
rhythm/phase by construction. Then: does adding A_1 (i.e. H4) close the permutation class at
lag 1? Exactly which permutations survive (preserve A_1)?

Q6 (The reachable-set rescue — THE CORE). The honest identifiability claim is RELATIVE TO
DYNAMICS, not absolute. Define the reachable set of room states under dynamics (a)–(c).
PROVE or REFUTE: there is a computable c(β, γ, switch sizes) > 0 such that for any two
reachable states s, s' (same N), if ‖s − s'‖_F ≥ δ (Frobenius distance of N×7 window
matrices) then ‖H4(s) − H4(s')‖ ≥ c·δ, OUTSIDE an explicitly named exceptional set.
Equivalently: H4 is bi-Lipschitz on the reachable set modulo the named class. If false as
stated, repair it to the strongest true version you can prove, and NAME the exceptional
class — in particular: can the stated dynamics (acclimation + bounded charisma + switches)
GENERATE a mean- and covariance-preserving state change that fools H4? That is the kill-shot
class; characterize it or prove it empty.

Q7 (Verdict). One paragraph: is "define the room state-hash as H4 and prove identifiability
relative to the room dynamics" mathematically sound as a doctoral thesis core? Name the
