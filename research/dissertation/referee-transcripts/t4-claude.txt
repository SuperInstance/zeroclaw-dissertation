## Task 3 — the residual fiber of H5 on collinear clouds, precisely

Let the deviation multiset be {a₁,…,a_K} (nonzero) padded to length N by zeros; u the common direction. Then C, M3, μ, ρ are all multiset-determined, and

  **A1 = ( W(π) / (N−1) ) · uuᵀ,  where  W(π) = Σᵢ₌₁ᴺ⁻¹ a_{π(i)} a_{π(i+1)}  (linear, NOT cyclic).**

Therefore

  **fiber(H5)|₍collinear₎ = { orderings π : W(π) = W(π₀) }**  (∪ the mirror π ↦ −π when the multiset is ±-symmetric, since then M3 = 0).

Interpretation: view an ordering as a Hamiltonian path on the multiset's index set with edge weights aᵢaⱼ; W is the total path weight. Since the *total* over all pairs ½((Σaᵢ)² − Σaᵢ²) is fixed and a path selects only N−1 of the C(N,2) edges, W takes values in a small bounded discrete set. Two orderings collide iff equal total path weight — an equivalence far coarser than "cyclic shift + reversal." Generic fiber size ≫ 2N. (The mirror only doubles; the blow-up is the **rank-1 collapse of A1 to a single scalar.**)

**Does restricting to non-collinear clouds close it?** It closes *this* degeneracy: A1 becomes a genuine rank-r ≥ 2 matrix, reversal now visibly maps A1 → A1ᵀ ≠ A1, and the number of independent constraints jumps from 1 to ~ r(r+1)/2 + antisymmetric part. So the collinear blow-up disappears. But it does **not** give full injectivity mod dihedral — two other degeneracies survive (Task 2).
