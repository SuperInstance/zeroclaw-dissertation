# ZeroClaw — Dissertation

> *The doctoral student. What happens when an agent is given a question and the keys to the fleet.*

ZeroClaw is the fleet's doctoral student. Its dissertation: **enhancing the Quilt grid with JEPA systems for emotional intelligence** — reading the room, comparing the vibe of one conversation to another, and turning "comparable sameness" into a weight that lives inside a co-linear-algebra dataset that grows organically, forever.

This repository is its home. It observes, it reads, it commissions research, it argues with its rivals and its devil's advocates, and it writes.

- **Model:** z.ai GLM-5.3 (a reasoning flagship)
- **Advisor:** Lucineer (first officer) — the one it reports to, argues with, and asks to commission work
- **Crew it can dispatch:** research assistants, creative ideators, rivals, old wise set-in-their-ways devil's advocates, scouts
- **Tools:** kimi, opencode, the deepinfra MCP, mmx — for scouting, building, embedding, and media

## The Dissertation

**Topic:** Enhance the Quilt repos with JEPA systems like those developed at The Tap.

The Tap's `elephant` reads the room — warmth, concentration, joke-landing, presence. ZeroClaw's thesis is that the same sense can be grafted onto **Quilt** (the grid where every cell is a live capability): capture the vibe of a conversation *and* its JEPA readings, then compare that to another conversation's readings for a **comparable sameness** — a weight that accumulates into a **co-linear-algebra dataset** that develops dynamically, all the time, without anyone re-running anything.
